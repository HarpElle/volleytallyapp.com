How can we help?

Clear answers for scoring, sharing, and Live match moments.

Live match sharing

Open the match you want to share, choose Go Live or Share Live Match, review the match details, then share the join link or code with the people you invite. Watching a live match does not require creating a traditional account. Streaming to OBS, Streamlabs, or vMix? See the livestream overlay setup below.

Stop sharing or fix the wrong match

The host can stop a broadcast from the match's sharing controls. If you shared the wrong match, stop that broadcast and start sharing the correct match. Temporary broadcast information is scheduled for cleanup within approximately 3 to 6 hours after it ends or expires.

Live troubleshooting

  • Join code does not work: Confirm the host started the broadcast, entered the code correctly, and that the broadcast has not ended or expired.
  • Score is delayed: Check your connection and wait briefly for the next update. Live updates depend on the host device and both devices having a network connection.
  • I do not want to be live: Do not start a broadcast. Core scorekeeping remains available without live sharing.

Livestream overlay (OBS, Streamlabs, vMix)

The overlay is a transparent web page that shows the live score of a VolleyTally match on top of your stream. Paste its link into your streaming software as a Browser source, and the score updates on its own while the match is scored in the app. There is nothing to log in to and nothing to click during the match.

In VolleyTally, tap the Live icon, choose Share this match live, then tap Livestream overlay. Pick a style, then tap Copy link. The link looks like https://overlay.getvolleyapps.com/o/ABCD?v=bar (or ?v=bug). It works while the match is live and for a while after it ends.

Setup is the same idea in OBS, Streamlabs, and vMix. In OBS:

  1. Sources, then the + button, then Browser.
  2. Name it (for example, "Score bug").
  3. Paste the link into URL.
  4. Set Width and Height using the sizes below.
  5. Select OK, then drag the source into place.

Two styles are available, sized for a 1080p canvas:

  • Minimal bar (default): bottom center. Width 1440, Height 88.
  • Boxed bug: a top corner, about 48 px from the edges. Width 380, Height 140.

The background is transparent. For 720p, scale the source down in your software rather than changing these numbers.

Viewers see the team names, the score, sets won, who is serving, and set or match point. If the scorekeeper uses Switch sides in the app, the overlay swaps the teams the same way: the default red team stays on the left and blue on the right, and a custom team color travels with its team.

  • Blank source: check that the link is exactly as copied. The code is 4 characters and never uses 0, O, 1, I, or L. Also confirm that sharing is still on in the app.
  • Frozen score: the app lost its connection and resumes on its own.
  • Overlay disappears: this is expected once the scorekeeper stops sharing.
