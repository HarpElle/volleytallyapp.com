Match formats

Set up the match you are actually playing.

VolleyTally supports familiar best-of-3 and best-of-5 formats, a 2-set option, and custom rules for league or tournament play.

Choose a starting format

Pick a preset for a common format, then use match settings if the number of sets or point targets need to change.

Customize the rules

You can set the number of sets, standard and deciding-set targets, the win-by margin, and optional score caps. Review these settings before the match begins so the scoreboard ends each set when you expect.

Serving side

VolleyTally tracks the serving side as scoring changes. Keep the indicator visible as an extra check during a fast match.
