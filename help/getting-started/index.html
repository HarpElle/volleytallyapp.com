Getting started

Start scoring in a few seconds.

VolleyTally is ready for a quick match with its defaults, or you can make each side feel like your teams before the first serve.

Set up the match

  1. Open a new match.
  2. Name the home and away teams and choose their colors if you want to personalize the scoreboard.
  3. Select a format that fits the match, then start scoring.

Score a rally

Use the score panels to add points as the rally ends. Keep the scoreboard in view to follow the set score and serving-side indicator.

Need to change the match format?

See match formats and rules before you begin, or adjust settings for the match you are playing.
